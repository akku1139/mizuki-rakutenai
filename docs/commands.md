# コマンド一覧

`@瑞稀` はボットへのメンションを表します。Discord と Fluxer のどちらのボットにメンションしても同じように動きます。

## AI アシスタント

サーバー内のテキストチャンネルかスレッドでのみ反応します (DM では反応しません)。

| コマンド | 動作 |
|---|---|
| `@瑞稀 <メッセージ>` | 瑞稀が返信します。添付ファイルも一緒に渡せます |
| `@瑞稀 clear` | 自分の現在の会話と待機中・生成中の処理を取り消します |
| `@瑞稀 clear <追加の依頼>` | 履歴をリセットし、そのまま新しい依頼を処理します |
| `@瑞稀 chatlist` | AI の処理待ち・処理中の件数と、現在ある会話の一覧を表示します |
| `@瑞稀 aimodel` | 自分が使っている AI プロバイダと、選べるプロバイダを表示します |
| `@瑞稀 aimodel <provider> [model]` | プロバイダと任意のモデルIDを保存し、自分の全チャンネルの会話をリセットします。モデルIDは `openai` のときだけ指定できます |

`aimodel` は `=aimodel` とも書け、`=aimodel` はメンション無しでも使えます。
OpenRouterのプロファイルを設定した場合は `=aimodel openai <OpenRouterのモデルID>` で選べます。
モデルIDは現在のプロバイダのカタログで確認し、存在しなければ変更しません。
`clear` と `chatlist` はメンションが必要です。`clear` の後には改行を含む追加の依頼も書けます。

詳しくは [ai.md](ai.md) を参照してください。

## 安価 (Discord のみ)

| コマンド | 動作 |
|---|---|
| `>>n` を含むメッセージ | n 件後 (1〜200) にそのチャンネルへ投稿した人を安価として通知します |
| `=anka` | このチャンネルで進行中の安価を一覧表示します |

## MiQ (Fluxer のみ)

| コマンド | 動作 |
|---|---|
| メッセージに返信して `めいく` または `make` | 返信先のメッセージから引用画像を作り、URL を返します |

## チャンネル同期 (Fluxer のみ・管理者用)

| コマンド | 動作 |
|---|---|
| `=syncsetup <Discord チャンネル ID>` | 実行した Fluxer チャンネルと指定した Discord チャンネルを同期します |

実行できるのはハードコードされた特定のユーザーだけです。詳しくは [fluxsync.md](fluxsync.md) を参照してください。

## `purge.js` (別プロセス・Discord のみ)

`purge.js` を別に起動している場合に限り使えます。

| コマンド | 動作 |
|---|---|
| `!purge [メッセージ ID]` | 直近3時間のメッセージを一括削除します。特定のロールを持つ人だけが実行できます |

詳しくは [scripts.md](scripts.md#purgejs) を参照してください。
