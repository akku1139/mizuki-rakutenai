# 単発実行のスクリプト

本体 (`index.ts`) とは別に、手動で実行するスクリプトが2つあります。

## emojisync.ts

Evex の Discord サーバーにあるアニメーション絵文字とスタンプを、Fluxer サーバーへコピーします。
静止画の絵文字は移行済みなので対象外です。

```sh
node --env-file=.env emojisync.ts
```

- `DISCORD_TOKEN` と `FLUXER_TOKEN` を使います
- コピー元とコピー先のサーバー ID はコードに書かれています
- **重複チェックをしないため、実行した回数だけ同じ絵文字・スタンプが増えます。** 一度きりの移行用です
- Fluxer の上限 (実質 524,286 バイト) を超えるものはスキップし、手作業での縮小が必要な旨をログに出します
- アニメーション絵文字は WebP で返されることがあるため、GIF を明示して取得します
- スタンプは discord.js の `stickers.create()` を使わず、JSON で直接 API に送ります
  (multipart で送ると Fluxer 側で中身が空とみなされるため)

## purge.js

Discord で直近のメッセージを一括削除するボットです。本体とは別のプロセスとして起動します。

```sh
node --env-file=.env purge.js
```

起動中は、次のコマンドを受け付けます。

```
!purge [メッセージ ID]
```

- 実行できるのは、特定のロール (`1255803402898898964`) を持つ人だけです
- 直近3時間以内のメッセージを、新しい方から100件ずつ一括削除します
- メッセージ ID を指定した場合は、そのメッセージより前から削除を始めます
- Discord の制限により、14日より古いメッセージは削除できません
- 3時間より前か14日より前のメッセージに到達した時点で終了します
- `DISCORD_TOKEN` を使うため、本体と同じボットでログインします
