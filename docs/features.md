# その他の機能

## サーバーログ

コードは `src/logging/mod.ts` にあります。

Evex の Discord サーバーと Fluxer サーバーで起きた次のイベントを、それぞれのログ用 webhook に embed で送ります。

| イベント | 色 | 内容 |
|---|---|---|
| メッセージ削除 | 赤 | 投稿者、チャンネル、削除された本文 |
| メッセージ編集 | 緑 | 投稿者、チャンネル、元メッセージへのリンク、編集前後の本文 |
| メンバー参加 | 水色 | 参加したユーザー |
| メンバー退出 | 黄 | 退出したユーザー |

- 対象のサーバー ID はコードに書かれています (Discord: `1255359848644608035`、Fluxer: `1493971310876907609`)
- フッターは `Evex Developers` / `Evex Developers@Fluxer.app` です
- 本文が変わっていない編集 (埋め込みの展開など) と、ログ用 webhook 自身の投稿の編集は記録しません
- キャッシュに無いメッセージが削除された場合、投稿者や本文は取得できません
- webhook の設定は環境変数 `DISCORD_LOG_WEBHOOK`、`FLUXER_LOG_WEBHOOK_ID`、`FLUXER_LOG_WEBHOOK_TOKEN` で行います

## 安価

コードは `src/anka.ts` にあります。Discord でのみ動きます。

2ch 風の安価です。メッセージに `>>n` と書くと、そのチャンネルで n 件後に投稿した人に対して、
瑞稀が「安価されました」とリプライし、安価を出した人にメンションします。

- n は1〜200。1つのメッセージに複数の `>>n` を書けます
- ボットの投稿は数えません
- `=anka` で、そのチャンネルで進行中の安価を `>>n (現在の件数/n) <メッセージの URL>` の形式で一覧表示します
- 進行中の安価はメモリ上にしかないため、再起動すると消えます

## コイン監視

コードは `src/coinwatch.ts` と `mexc.ts` にあります。Discord でのみ動きます。

MEXC の WebSocket (`wss://wbs-api.mexc.com/ws`) で 114514USDT の約定ストリーム
(`spot@public.aggre.deals.v3.api.pb@100ms@114514USDT`) を購読し、
30秒ごとに決まったチャンネル (`1468910632119308289`) へ次の内容を embed で投稿します。

- 現在価格 (直近の約定価格)
- 動向 (直近の約定が買いか売りか)
- 直近30秒の出来高
- 取引回数

- 30秒の間に約定が無かった場合は投稿しません
- 出来高は約定数量の合計です (表示の単位は USDT になっています)
- MEXC のメッセージは protobuf 形式で、`mexc-proto/` の生成コード (Apache-2.0) でデコードします
- `MexcWebsocketClient` は ping による接続維持と、切断時の再接続を行います

## MiQ

コードは `src/miq.ts` にあります。Fluxer でのみ動きます。

メッセージに返信する形で `めいく` または `make` とだけ送ると、返信先のメッセージから
「Make it a Quote」風の引用画像を作り、その URL を返信します。

- `@makeitaquote/openmiq` を使い、`https://miq.otnc.dev` の API を呼び出します
- API キーは環境変数 `OPENMIQ_TOKEN` で設定します
- 画像はカラーで作ります
- ボットが送った `めいく` / `make` には反応しません
